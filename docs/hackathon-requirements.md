## Sponsor-Specific Requirements

### Channel3 — $1,500 prize
Use the Channel3 API (100M+ products, 25,000+ brands) to power product discovery in your app. Integration via REST API or `@channel3/sdk` npm package. Free tier: 1,000 searches/month. [docs.trychannel3.com](https://docs.trychannel3.com)

### APIMatic — ×3 $1,000 prizes
Use the APIMatic Context Plugin for PayPal. Install via: `npx context-plugins install paypal`. Winning teams also get 6 months of APIMatic Business free. [context.apimatic.io/plugins/paypal](https://context.apimatic.io/plugins/paypal)

### AG Grid (AG Studio) — up to $5,000
Build self-serve dashboards, drag-and-drop charts, or an AI assistant using AG Studio. Boilerplate: [github.com/paypaldev/hackathon-paypal-ag-grid-boilerplate](https://github.com/paypaldev/hackathon-paypal-ag-grid-boilerplate)

### Render — up to $1,000 credits
Deploy and orchestrate AI agents on Render. Free tier: 750 instance hours/month, spins down after 15 min inactivity. [render.com](https://render.com)
