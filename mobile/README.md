# ProofBuy AI — Flutter Mobile App

Smart PayPal Shopping Assistant. Lets users describe what they want to buy,
compares AI-ranked products, and completes a verified PayPal checkout — all
from a single mobile flow.

---

## Prerequisites

- **Flutter 3.47.1+** — install via [flutter.dev](https://flutter.dev/docs/get-started/install) or Homebrew (`brew install flutter`)
- **Dart 3.13.1+** (bundled with Flutter)
- **Android SDK** with accepted licenses (see Common Failures below)
- Android emulator or physical device for testing

---

## Setup

```bash
cd mobile
flutter pub get
```

---

## Code generation

Freezed models, Riverpod providers, and JSON serialization are generated by
`build_runner`. Run this whenever you change any `@freezed`, `@riverpod`, or
`@JsonSerializable` annotated file:

```bash
cd mobile
dart run build_runner build --delete-conflicting-outputs
```

Generated files (`*.freezed.dart`, `*.g.dart`) are committed to the repository.

---

## Run on emulator

The default `BACKEND_URL` points to the Android emulator loopback address
(`10.0.2.2`), which maps to `localhost` on the host machine.

```bash
cd mobile
flutter run --dart-define=BACKEND_URL=http://10.0.2.2:8000
```

---

## Run on physical device

Replace `<your-machine-ip>` with the IP address of the machine running the
backend (find it with `ifconfig` / `ipconfig`). Make sure the device and the
machine are on the same network.

```bash
cd mobile
flutter run --dart-define=BACKEND_URL=http://<your-machine-ip>:8000
```

---

## Build debug APK

```bash
cd mobile
flutter build apk --debug --dart-define=BACKEND_URL=http://10.0.2.2:8000
```

The APK is output to `build/outputs/flutter-apk/app-debug.apk`.

## Common failures and fixes

| Symptom | Fix |
|---|---|
| `flutter doctor` shows Android licenses not accepted | Run `flutter doctor --android-licenses` and accept all prompts |
| `build_runner` complains about conflicting outputs | Add `--delete-conflicting-outputs` to the build command |
| Connection refused on emulator | Make sure the backend is running and use `10.0.2.2`, not `localhost` |
| Connection refused on physical device | Use the host machine's LAN IP, not `localhost` or `10.0.2.2` |
| iOS simulator listing issue | Focus on Android APK for demo; iOS build is not required |
